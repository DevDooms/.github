## 👋 Quem somos

A **DevDooms** é um time de desenvolvimento focado em criar soluções web para negócios locais.
Começamos entendendo como o negócio funciona no dia a dia, depois modelamos as regras e só então
desenhamos as telas, para que o sistema reflita a operação de verdade.

## 🧭 Como trabalhamos

- **Regras de negócio primeiro:** a lógica fica em funções puras, separadas da interface, para ser fácil de testar e mudar.
- **Protótipo navegável cedo:** o cliente clica, testa e opina antes de qualquer backend existir.
- **Tipagem de ponta a ponta:** TypeScript e validação com Zod para evitar surpresas.
- **Entrega contínua:** cada versão vai ao ar com uma demo pública.
